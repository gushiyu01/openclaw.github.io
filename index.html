from openclaw import Agent

# 创建一个OpenClaw代理实例
agent = Agent(
    model="claw-3.5-sonnet",
    tools=["browser", "python", "shell"]
)

# 交给它一个任务
result = agent.run("""
    访问 GitHub 上 openclaw 仓库的 issues 页，
    提取所有标有“good first issue”的标题，
    并用表格形式保存到 report.md
""")

print(result)

核心能力 — 不只是对话

自主任务规划

基于思维链动态拆解复杂目标，递归规划子任务，并能根据中间结果实时调整策略。

全场景工具调用

内置浏览器自动化、Python解释器、Shell、文件读写、API请求等工具，也可自定义扩展。

代码即行动

代理能自行编写、调试、运行代码（Python/JavaScript等），实现数据处理、爬虫、分析等。

多模态感知

支持图像、PDF、表格等多格式输入；可利用视觉模型理解屏幕截图、图表内容。

长期记忆

通过向量存储记录历史经验，跨会话复用知识，持续优化任务执行效率。

安全沙箱

所有代码和工具均在隔离容器内执行，提供权限控制与审计日志，保障环境安全。

🚀 快速开始 两分钟启动代理

1

安装 OpenClaw

通过pip一键安装核心库

pip install openclaw
2

配置API密钥

设置你的模型提供商密钥（OpenAI/Anthropic等）

export OPENAI_API_KEY=sk-...
3

运行首个任务

启动交互式CLI或直接运行脚本

claw run "总结今天的Hacker News头条"
